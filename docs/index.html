FlexText → OneStory Injector

Add a story from a FLEx / FlexText Editor interlinear file (.flextext) into a OneStory Editor project — word glosses included, nothing retyped.

⬇ Download for Windows

Free, no admin rights needed. If the releases page shows no installer yet, the first Windows build is still in testing — check back soon.

What it does

  • Your team transcribes, glosses and back-translates a recording in FlexText Editor (or FLEx).
  • This tool adds that story to your .onestory project as a new story: baseline text, word-by-word gloss line, and free translation, all aligned.
  • It asks whether the story is biblical or non-biblical, who crafted it, and which story set it belongs in — then shows a preview before anything is written.

Before you inject

  1. Close OneStory Editor.
  2. Use a copy of your project until you have checked the result — this tool writes into the project file.
  3. A timestamped backup is made automatically before every injection, and Undo last injection restores it.

After injecting

  • Open the project in OneStory Editor and read the new story through.
  • Words with no gloss show *** — that is deliberate: it keeps every other gloss under the right word. Fill them in as you gloss.
  • A < under a word means it belongs to the word before — the two were glossed together as one unit (ru weni over river_bank <). Nothing to fix there.
  • For Bible stories, adding verse anchors is your next task — OneStory's task list will say so.

Safety

  • Everything outside the added story is left byte-for-byte untouched — verified on every write, so Send/Receive stays clean for your team.
  • The tool refuses rather than guesses: if the project changed on disk, if a story set is ambiguous, or if an undo would overwrite someone's newer work, it stops and says why.
